## 让 Agent 安装

将下面的指令复制给编程 Agent：

```text
将 https://github.com/wcqqq1214/codex-dot-send-motion 接入当前应用。
按 docs/api.md 操作，确认 React 19 和 ESM 兼容性。
单独克隆组件库，使用仓库指定的工具链运行 npm ci && npm pack，
再用应用现有包管理器安装生成的 .tgz。
导入 'codex-dot-send-motion/styles.css'，按文档接入 captureSend。
验证类型检查、构建、发送动效和减少动态效果。
```
