## 让 Agent 安装

将下面的指令复制给编程 Agent：

```text
使用当前应用的包管理器安装 codex-dot-send-motion。
阅读 https://github.com/wcqqq1214/codex-dot-send-motion/blob/main/docs/api.md，
确认 React 19 和 ESM 兼容性。
导入 'codex-dot-send-motion/styles.css'，按文档接入 captureSend。
验证类型检查、构建、发送动效和减少动态效果。
```
